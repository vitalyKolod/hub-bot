# Видео для раздела «Туториалы»

Положите MP4-файлы прямо в эту папку. Имя файла должно совпадать с одним из названий ниже:

- `create-team.mp4` — Как создать команду
- `join-team.mp4` — Как вступить в команду
- `buy-subscription.mp4` — Как купить подписку
- `buy-multiple-subscriptions.mp4` — Как купить несколько подписок
- `check-subscription-and-access.mp4` — Как проверить подписку и найти доступ
- `add-team-member.mp4` — Как добавить участника в команду
- `renew-subscription.mp4` — Как продлить подписку
- `connect-propresenter.mp4` — Как подключить ProPresenter
- `contact-support.mp4` — Как написать в поддержку

После добавления файла ролик будет доступен при следующем открытии соответствующего туториала. Для надёжного воспроизведения в Telegram сохраняйте видео как MP4 с кодеком H.264 и звуком AAC.
